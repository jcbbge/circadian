**Short answer.** Sketch 1's value is a practice, not a representation. Sketch 2's value is one operation, a directed link addressed at the occasion, and it is the clearer slice to carry. Both sketches share a primitive the default does not name: a derived record that points at its source and can be withdrawn without touching the source.

## Sketch 1: the aid

The aid and the ordinary note carry identical information, and the sketch is honest about that. A competent agent reading "from the temporary flat: market via riverside; library via hill steps" already answers "I'm at the station" with "that note doesn't cover it." So the representation adds nothing a reader cannot do.

What the aid adds is two deliberate acts. First, authoring: the agent decides, while reasoning is fresh, that this association is worth keeping as a tool. Second, withdrawing: the agent decides the tool is done while the experience of learning Lumen stays. The "Keep" line is the only line in the block that an ordinary note would not naturally contain, and it is the important one. It names the boundary between retiring an aid and forgetting an experience.

That boundary already has a home. The ledger's forget event hides a record from render and scoped wake, requires a reason, and leaves the file (`templates/MIND-SPEC.md:89`). An aid that is forgotten-with-reason while its source episode stays is exactly "retire from routine use, keep the account." No new lifecycle operation is needed. What is new is that the aid exists as a separate thing that can be forgotten on its own.

Remove from the sketch: "Purpose" duplicates "Basis." "Reconsider when" and "Retire when" are both "use when, else unknown." "Remaining information" is the one slot with operational content, because it turns "does this apply?" into a check of whether the request supplies the missing inputs. Hidden work the sketch undercounts: the aid has to be in context for the agent to decide it applies, so it rides along on every nearby recall whether or not it fires. That is the selection cost, and it is the same cost the operator's gateway paid.

The partial-evaluation framing is a lens, not a law. It does supply one falsifier worth keeping: an aid applied to a request must yield what reasoning over S1 would have yielded. If it ever yields more, it has stopped being a shortcut and become a claim.

Answer to the sketch's own question: the value is in the practice. If the agent can be given the habit of authoring and forgetting aids, the note format barely matters.

## Sketch 2: the dinner

Here the addition is an operation. The reflection R1 says "that dinner" and "permission to be quiet." It does not say Noor, Mira, or dessert. The cue "that evening with Noor when I felt comfortable being quiet" lexically reaches D1 through Noor and "at ease," and reaches R1 only through "quiet," weakly. The relational index can score both, but nothing ties them. The line "I2 revisits I1 about dinner-D1" is what makes the two accounts travel together regardless of shared vocabulary.

An ordinary note can get the same effect if the writer restates the anchors: "reflection on Mira's dinner where Noor cooked." So the honest comparison is: the link is a cheaper and more reliable way to guarantee co-retrieval than hoping every later reflection repeats the right nouns. That is a real but modest benefit, and it is testable.

The second thing the sketch adds is vocabulary. "Revisits, may coexist" is a relation the ledger does not have. Supersede retires a loser and transfers weight. Contradiction opens an undirected tension awaiting resolution (`src/atoms.ts:46-64`). Neither says "a later account of the same thing, both kept." That relation is new and small.

Remove: the roles table. Host and cook are pleasant but neither use case needs them. The "mentioned but absent" list is a rule, not data. Storing absentees for every mention is a maintenance trap. Keep the rule as a boundary on interpretation and drop the slot. Hidden work: the sketch acknowledges that matching "that dinner" to D1 is the hard part. On paper it is given. In practice it is the whole cost.

On mathematics: the globular sketch earns one concrete constraint. A 2-cell requires both 1-cells to share endpoints. Translated, the link must name the occasion both interpretations are about. That is exactly the field that bridges retrieval. Without it, "I2 revisits I1" is a bare pointer between two sentences and the retrieval benefit disappears. So the shared-boundary requirement is doing design work here. Incidence-over-clique is not exercised by a single occasion. The sheaf "same occasion is a premise" point is a lens and a correct one.

## Applicability, validity, usefulness

These have three different evidence sources, and that is how to keep them apart without an engine. Applicability is answered by the present request and can sometimes be checked mechanically, for example a date or a named scope. Validity is answered by later evidence about the world, such as "the riverside path is closed," and is supersession-shaped. Usefulness is answered only by the person, as in "no more reminders." Each defaults to unknown. Unknown limits reliance, never blocks the task.

The only mechanical piece worth having is a date or event condition checked at wake without a model. Everything else is the agent reading the record and judging. Retirement, as above, is the existing forget event applied to the derived record alone.

## The slice to carry forward

The shared primitive across both sketches is a derived record that points at its source and can be forgotten independently of it. The aid is one instance. The reinterpretation link is another. Of the two, the link is clearer because its benefit is observable at the point of use.

Proposed single observation, not authorized now: in the existing mind, find one real pair consisting of an episode and a later reflection on it that does not repeat the episode's anchor words. Issue a recall cue that lexically matches only one of them. If current retrieval already returns both, the link adds nothing and the practice-only reading of both sketches stands. If it returns one, the link's value is credible with one example and no model call.

One connection the sketches missed: the aid in Sketch 1 is itself an I2 in Sketch 2's sense, an agent-authored account of a source, pointing back at it with a stated relation. If that is right, the two examples are not two augmentations. They are one record shape with two relation labels, "prepared from" and "revisits," and the question for the operator becomes whether that one shape earns a place beside the atom.
